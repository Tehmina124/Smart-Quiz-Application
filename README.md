# 📌 Overview

Smart Quiz Application is a console-based application developed using Python. It allows users to select quiz categories and difficulty levels, answer multiple-choice questions within a limited time, calculate scores automatically, and save results for future reference.

This project demonstrates the implementation of Python programming concepts including randomization, timers, file handling, dictionaries, loops, and conditional statements to build an interactive quiz system.

---

# ✨ Features

- 📝 Multiple Quiz Categories (Python, AI & Cyber Security)
- 🌍 All Categories Mode
- 🎯 Easy & Hard Difficulty Levels
- ⏱️ 15-Second Timer for Each Question
- 🔀 Random Question Selection
- 📊 Automatic Score Calculation
- 📈 Percentage & Pass/Fail Result
- 💾 Save Quiz Results in Text File
- 🔄 Play Again Option
- 🖥️ Interactive Command-Line Interface
